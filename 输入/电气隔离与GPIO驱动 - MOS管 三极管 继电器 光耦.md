## GPIO（General Purpose Input/Output，通用输入输出）
GPIO 是 MCU 的通用输入输出接口，可配置为输入（检测外部电平）或输出（产生高/低电平），本质是数字控制接口而非电源——高电平≈3.3V（或 5V）、低电平≈0V，对应逻辑 1 和逻辑 0。


## 1. MOSFET 本质

MOSFET（Metal-Oxide-Semiconductor Field-Effect Transistor）是一种**电压控制型电子开关**，用于让 MCU 控制远大于 GPIO 能力的负载。

MOS 是 MCU 与大功率负载之间的电子开关，**栅极（G）接收控制信号、漏极（D）承载负载电流、源极（S）接参考端（NMOS 通常接地）**，GPIO 本身不给负载供电，只负责驱动 G 极。在智能硬件中，**NMOS + 低边开关 + PWM** 是最常见且应优先掌握的驱动拓扑。
### 三个引脚

| 引脚  | 名称     | 作用                |
| --- | ------ | ----------------- |
| G   | Gate   | 控制输入，几乎无持续电流      |
| D   | Drain  | 接负载，承载工作电流        |
| S   | Source | 电流返回端（NMOS通常接GND） |
|     |        |                   |
工作电流和控制信号是两条不同的路径

# 2. 为什么 MCU 不能直接驱动 LED？
MOSFET 为电压控制型开关，G 极几乎无持续电流，MCU 通过 GPIO/PWM 提供控制信号，而负载电流由外部电源经由 D‑S 路径提供。以 12V/24W 的 LED 灯板为例，负载需 2A，而 Arduino GPIO 仅能提供约 20mA，所以必须用 MOS 放大驱动能力。三个引脚分工明确：G 为控制输入，D 接负载，S 为电流返回端（NMOS 接 GND）。工作电流和控制信号走的是两条完全独立的路径。


# 3. NMOS 与 PMOS
NMOS 接在负载与 GND 之间（低边开关），MCU 可直接驱动，电路简单、导通损耗低且最适合 PWM，是学习阶段的首选；PMOS 接在电源与负载之间（高边开关），MCU 通常无法直接驱动 12V 高边，需要额外的电平转换或驱动芯片，电路复杂，初学不推荐。

# 4. PWM 调光

PWM 并非降低电压，而是通过高速开关 MOS，改变导通时间的占比（占空比）来调节平均功率。LED 因视觉暂留，看到亮度连续变化；调光时频率应高于 200Hz（Arduino 默认 490Hz/980Hz 完全足够），电机控制常用数 kHz 至 20kHz——频率过低会闪烁或产生可听噪声，过高则开关损耗显著增加。

# 5. 为什么需要续流二极管？

适用于：

- 电机
- 风扇
- 电磁阀
- 继电器

驱动电机、继电器线圈、电磁阀等感性负载时，MOS 关断瞬间线圈磁场塌陷会产生反向高压，可能击穿 MOS，必须在感性负载两端反并联续流二极管（如 1N4148、SS14），为电感电流提供续流回路，安全释放能量。纯 LED 这类阻性负载通常无需续流二极管。

# 6. MOS vs 三极管（NPN/PNP）

| 项目       | BJT(NPN/PNP) | MOSFET |
| -------- | ------------ | ------ |
| 控制方式     | 电流控制         | 电压控制   |
| 输入阻抗     | 低            | 极高     |
| GPIO持续供电 | 需要           | 几乎不需要  |
| 发热       | 较高           | 较低     |
| 高频PWM    | 一般           | 非常适合   |
| 大电流      | 一般           | 优秀     |

现代产品绝大多数功率驱动均采用 MOSFET

# 7. 继电器 vs MOS

| MOS   | 继电器     |
| ----- | ------- |
| 无机械触点 | 有机械触点   |
| 可PWM  | 不可PWM   |
| 高速    | 较慢      |
| 寿命长   | 有机械寿命   |
| 静音    | 有吸合声    |
| 适合DC  | AC/DC均可 |

继电器适用于：

- 220V交流
- 完全断电
- 大功率隔离

MOS 更适用于：

- LED
- 电机
- 风扇
- 电池产品

# 8. 光耦（Optocoupler）
光耦通过内部 LED 发光、光敏器件接收实现电气隔离，信号靠光传递，完全切断电连接，用于 MCU（如 3.3V）安全地控制 220V 设备，同时提高抗干扰能力。

# 设计注意事项

- **优先选逻辑电平 NMOS**（3.3V GPIO 可直接驱动）**标准 MOS 往往需要 10V 栅压才能完全导通，而逻辑电平 MOS（如 IRLZ44N）在 3.3V 或 5V 时就能达到极低的 Rds(on)**。对 3.3V 系统的设计尤其致命，务必确认所选型号在目标 GPIO 电平下的 Rds(on)。
- **Gate 通过电阻接地的具体理由**
    - **栅极串联 10–100Ω**：不仅抑制振铃，还能限制 MCU 引脚对栅极电容充放电的瞬时电流，保护 GPIO。
    - **栅源下拉 10kΩ**：避免上电或 GPIO 高阻态时栅极悬空，造成 MOS 半导通烧毁。这是量产设计中绝不能省的。
- 感性负载必须加续流二极管。
- **共地**  
    MCU 的 GND 必须和功率电源的 GND 直接相连，否则栅极信号没有参考回路。这是新手最容易翻车的地方。
- MOS 要关注：
    - V<sub>GS(th)</sub>（栅极阈值，不能作为完全导通依据）
    - **R<sub>DS(on)</sub>（导通电阻，越小越好）**
    - 最大电流 I<sub>D</sub>
    - 最大耐压 V<sub>DS</sub>
- PWM 频率需结合负载选择，过低会闪烁，过高会增加开关损耗。
- LED 调光 200 Hz 以上即可不闪烁，Arduino 默认 490 Hz/980 Hz 完全够用；电机控制频率常在几 kHz 到 20 kHz。过低人眼/耳朵可感，过高开关损耗显著增加。
