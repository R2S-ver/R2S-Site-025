# 设计师选型工具三问：

1. 输入输出压差多大？ → 压差>3V、电流>0.3A，别用 LDO，用 Buck。
    
2. 系统对噪声敏感吗？ → 无线模块、高精度模拟电路倾向 LDO 或加滤波。
    
3. 空间和散热条件？ → 全封闭小外壳选开关式，避免热堆积。

# 电源架构——从电池到负载的能量管理

设计师核心目标：看到任何 PCB，先找出电源入口与功率路径，理解电压转换与热设计的取舍。

## 1. 电源系统是多级转换体系

### 知识点
电不是“供给”就完了，而是一套多级转换与分配系统。核心不是“产生电”，而是把能量以正确的电压、电流、噪声水平分配给各模块。

### 电路逻辑
典型产品电源链：

```
输入(USB/电池) → 保护(保险丝、防反接) → 充电管理 → 电池 → DC/DC转换 → 多路电压轨 → MCU/传感器/LED/电机
```

不同模块需不同电压：

| 模块 | 典型电压 |
|------|----------|
| MCU | 3.3V |
| Arduino | 5V |
| 传感器 | 1.8~3.3V |
| LED | 2~3V |
| 大功率负载 | 12V/24V |

产品内部常有 5V、3.3V、1.8V 等多条电源轨。

### 工业产品应用
任何电池或 USB 供电产品背后都有这条功率流。从手机、电动牙刷到智能灯，都离不开输入保护 → 充电 → 电池 → 稳压 → 负载的基本结构。

### 设计注意事项
- 功率路径上每一级都有能量损耗，要逐级评估效率。
- 多电压轨需合理规划，敏感电路供电可能需额外滤波。
- 保护器件（保险丝、防反接）虽简单，却决定了产品的安全底线。

## 2. LDO 线性稳压器

### 知识点
LDO（Low Dropout Regulator）本质是线性降压：多余的电压直接变成热量耗散。发热公式：

```
P_loss = (Vin - Vout) × I
```

并非 LDO 永远低效：压差小（5.5V→5V，1A → 0.5W，η≈91%）很好；压差大（12V→5V，1A → 7W，η=42%）极差。  
特性：电路简单、成本低、噪声低、输出稳定；缺点是大压差/大电流发热严重。

### 电路逻辑
典型应用电路极为简单：输入电容 + LDO + 输出电容。9V 接 LM7805 输入，输出 5V 给负载，输入输出压差 4V 全部以热形式消耗在稳压器上。

### 工业产品应用
- 3.6V 锂电池 → 3.3V 给 MCU 或传感器供电。
- 对噪声敏感的模拟/射频电路（如音频放大、ADC 基准）。
- 不适合 12V→5V 大功率场景，否则要加庞大散热器。

### 设计注意事项
- 计算功耗 P_loss，结温 = 环境温度 + P_loss × θJA。确保在安全范围内。
- 大压差、大电流场合优先使用开关电源，不要强行用 LDO。
- PCB 铜皮可以作为 LDO 的散热器，扩大覆铜面积降低热阻。

## 3. Buck 降压型开关电源

### 知识点
Buck 不是烧掉电压，而是通过 MOS 高速通断＋电感电容储能平滑，高效降压。效率通常 85%~97%。核心器件：MOS 管、电感、续流二极管（或同步整流 MOS）。代价是有高频纹波，外围元件较多。

### 电路逻辑
MOS 开关高频导通/关断，将输入电压斩波成方波，经 LC 低通滤波得到平稳直流。占空比 D ≈ Vout/Vin。例如 12V→5V，占空比约 42%。

### 工业产品应用
- 压差大于 3V、电流大于 0.3A 时优先选用，如 12V 供电系统、电池降压给大功率负载。
- LM2596 模块是经典 Buck 方案，可调输出，广泛用于原型开发和小批量产品。

### 设计注意事项
- 电感选型关键：饱和电流必须大于最大负载电流，否则电感饱和导致 MOS 烧毁。
- 开关节点 layout 要短而粗，减小 EMI。
- 敏感电路可在 Buck 后加一级 LDO 或 π 型滤波抑制纹波。

## 4. Boost 升压与 Buck-Boost 升降压

### 知识点
- **Boost**：抬升电压。单节锂电 3.7V → 升压到 5V 或 12V。解决“电源电压不够”的问题。
- **Buck-Boost**：输入电压可能高于或低于目标输出时，自动在 Buck 和 Boost 模式间切换，维持稳定输出（如 5V）。

### 电路逻辑
Boost 拓扑：开关管导通时电感储能，关断时电感与输入串联通过二极管向输出释放能量，输出电压高于输入。  
Buck-Boost（四开关或 SEPIC）：根据反馈自动调节 MOS 开关，3V 输入时以 Boost 模式工作，8V 输入时以 Buck 模式工作，维持 5V 输出。

### 工业产品应用
- 锂电池设备驱动 5V 电路、12V LED 灯条用 Boost。
- 电池电压变化范围宽（如 2.7V~4.2V）但需稳定 3.3V/5V 输出的场合用 Buck-Boost。

### 设计注意事项
- Boost 电路开机时可能有浪涌电流，需软启动。
- Buck-Boost 效率通常略低于单纯 Buck 或 Boost，因为需要更多开关动作。
- 输出端不能直接短路，保护机制需要设计。

## 5. 电池充电管理与保护板

### 知识点
锂电池 **绝不能** 直接接 5V 充电，必须用充电管理 IC。  
- **TP4056**：线性充电，恒流→恒压（4.2V），多余电压变热量，底部大焊盘靠 PCB 铜皮散热。
- **保护板**（DW01+8205A）：监控过充(>4.25V)、过放(<2.5V)、过流、短路，异常时立即切断电路。

TP4056 是充电规则执行者，保护板是安全兜底者，两者缺一不可。

### 电路逻辑
完整链路（单节锂电）：

保护板通常和电池绑定为一体
```
输入 5V → TP4056 → 【锂电池 + 保护板(一体化)】→ Buck/Boost → 各路负载
                 ↑____充电____↑   ↑____放电____↑
```

- 充电时：TP4056 控制电流流向电池，保护板监测电压。
- 放电时：电流从电池经保护板流出，再经 DC/DC 变换给负载，保护板监测过放/短路。

### 工业产品应用
所有使用单节锂电池的消费电子产品（耳机盒、手持风扇、玩具等）都采用这种结构。常见的 TP4056 充电模块上通常已经集成了 DW01+8205A，形成一体式充电保护方案。

### 设计注意事项
- TP4056 设定充电电流时需考虑 USB 供电能力和散热，默认 1A 对小型电池可能偏大。
- 保护板必须与电池直接连接，不能放在主板远端。
- 布局时 TP4056 底部热焊盘必须铺大面积铜皮并打过孔，否则充电时会过热。

## 6. 效率与热设计——即便高效率也需要散热

### 知识点
Buck 效率 95%，输出 50W → 仍约有 2.6W 损耗，足够让 MOS 明显升温。  
MOS 损耗来源：导通损耗 P=I²R_DS(on)；开关损耗（电压电流交叠，高频下显著）。  
热路径设计：MOS → 导热垫 → 金属中框/铝壳 → 空气。利用产品外壳作散热器。

### 电路逻辑
开关电源中，MOS 和电感是主要发热元件。功率回路 PCB 走线电阻也会产生额外损耗。需要分析热源位置，规划热量传导路径。

### 工业产品应用
手机充电器、笔记本电源适配器常使用外壳作为散热体。工业设备可能采用金属底板散热，封闭式小产品利用 PCB 铜皮和填充导热胶。

### 设计注意事项
- 不要只看效率数字，要计算绝对损耗功率。
- 电感的 DCR 也会发热，选型时需注意。
- 热仿真或温升测试必不可少，确保最高环境温度下器件不超结温。
- 外壳开孔或导热界面材料的选择属于结构与电子协同设计。

## 7. 电源选型三问与综合实践

### 知识点
设计师选型工具三问：  
1. 输入输出压差多大？ → 压差>3V、电流>0.3A，别用 LDO，用 Buck。  
2. 系统对噪声敏感吗？ → 无线模块、高精度模拟电路倾向 LDO 或加滤波。  
3. 空间和散热条件？ → 全封闭小外壳选开关式，避免热堆积。

### 案例
- LM7805（线性）：9V 输入接 7805，输出接 Arduino。运行 5 分钟触摸芯片，升温明显。效率约 55.6%。
- LM2596 模块（Buck）：先调至 5V 输出，同样负载。几乎不热，效率约 92.6%。
重点：便携电池供电产品必须优先选择开关电源。

### 拆解观察：旧手机充电器里的电源流
功率流框图：
```
AC 220V → 保险丝电阻 → 共模电感 → 整流桥 → 400V 大电解电容 → 高频变压器初级 → 开关管(集成IC) → 变压器次级 → 肖特基整流 → 电解滤波 → 5V USB 输出
```
关键元件：光耦跨越高低压区传递反馈信号，同时提供安全隔离。找出 PCB 上这些模块，培养追踪功率路径的习惯。

### 设计注意事项
- 选型时需考虑未来可能的最大负载电流，留足余量。
- 考虑器件供货和成本，成熟方案（如 LM2596）适合快速验证。
- 电磁兼容（EMC）在开关电源中不可忽视，必要时加屏蔽罩或共模扼流圈。

## 核心认知
- 电源设计的核心是能量分配而非“产生电”。
- LDO 与 Buck 不是替代关系：LDO 是低功耗、低噪声方案；Buck 解决大功率、高效率需求。
- 开关电源效率高，但绝对损耗仍可观，必须进行热设计。
- 设计链路：能源流 → 电压转换 → 热路径 → 结构集成，这是电子与工业设计的接口。
- 充电管理（TP4056）制定充电规则，保护板负责安全兜底，DC/DC 翻译电压。

## 常见疑问

### 保护板为什么必须和电池一体化？
保护板需直接、无延迟监视电芯电压与电流，通常用镍带焊在电芯上。若放在主板上，导线电阻和接插件松动会严重影响保护可靠性。

### 可以直接用 TP4056 给带保护板的电池充电吗？
可以，这正是标准做法。TP4056 执行恒流恒压充电，保护板作为最后防线，在异常过压时切断电路。

### 为什么我的 Buck 电路依然发烫？
实际损耗 1~2W 若没有足够散热，芯片结温会迅速上升。检查电感饱和电流、MOS R_DS(on)、PCB 铜皮面积及导热路径。

## 拓展阅读

### AC-DC 拓扑功率等级与选择

**Flyback（反激）**

- 几十瓦以下霸主，元件少、成本低、可隔离、可多路输出。
- 应用：手机充电器、路由器电源、小家电、LED 驱动。
    
**Forward（正激）**

- 功率再大一些，100W 以上。效率更高，但电路更复杂。
    
**Push-Pull（推挽）**

- 功率再往上，常见于汽车逆变器、大功率 DC/DC 变换器。
    
**Half Bridge（半桥）**

- 适用场景：服务器电源、工业电源、UPS。
    
**Full Bridge（全桥）**

- 更大功率等级，1000W~5000W 广泛使用。
    
**LLC（谐振）**

- 现代电脑电源几乎必备。典型 ATX 电源架构：PFC → LLC → 同步整流 → 12V，效率可达 90%~96%。

### 开关电源纹波对策

敏感电路可在 Buck 后加一级 LDO 或 π 型滤波（电容-电感-电容）。开关+LDO 组合兼具高效与低噪声。

**输入直流电源 → Buck → LDO → 负载**

1. **Buck 在前负责“高效粗降压”**
    
    - Buck 处理大压差（如 12V→5.5V），效率高达 90% 以上，只产生很少热量。
        
    - 将电压降到略高于 LDO 最终输出电压的水平（通常高出 0.3~0.5V）。
        
2. **LDO 在后负责“精准稳压与净化”**
    
    - 压差很小（仅 0.3~0.5V），P_loss 极小，不会发热。
        
    - LDO 的高电源抑制比（PSRR）能将 Buck 输出的高频纹波大幅衰减，输出极其干净的直流电。

### 电池选型与电源树规划

先确定系统电压需求，再根据电池特性（锂电 3.7V、镍氢 1.2V）决定是否需要升压或升降压，避免后期大改。
