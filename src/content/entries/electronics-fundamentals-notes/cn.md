# 电压与电流

## 简单理解——水管类比

为了建立直观理解，我们用水管来类比：

- **电压（V）：** 等同于**水压**——推动电荷在电路中流动的势能差
- **电流（I）：** 等同于**水流速度**——导体内电荷的实际运动
- **电阻（R）：** 等同于**管道粗细**——管道越窄，对水流的阻力越大

> **欧姆定律：** V = I × R

## 深入理解

当我们按下开关，灯泡瞬间亮起。电子是从电池以光速冲向灯泡的吗？**完全不是。**

### "龟速"电子与"光速"能量传播

在金属导体（如铜线）内部，充满了自由电子，形成所谓的**"电子海"**。

- **漂移速度：** 电路通电后，电子在电场力的驱动下向前移动。但因不断与铜原子晶格碰撞，其实际移动速度极其缓慢——通常仅**每秒几微米到几毫米**（比蜗牛还慢）。
- **电磁场的建立：** 如果电子移动如此之慢，为什么灯泡会瞬间亮起？因为真正传递能量的不是电子本身，而是**电磁场**。开关闭合的瞬间，电场沿导线以**接近光速**（约 3 × 10⁸ m/s）建立。
- **物理现实：** 自由电子原本就存在于整条导线中。电场一旦建立，沿线所有电子几乎在同一瞬间接收到电场力（F = qE）的指令并一起开始运动。

### 电压的本质：电场力的空间积累

在物理学中，电压的本质是**电势差**。电池或电源的作用是利用化学能或磁能强行分离正负电荷，从而在空间中建立**电场**。当电子在电场中移动时，电场力对其做功。

因此，电压不是某种看不见的气体压力，而是**电场对电荷施加的"无形推力"在空间上的累积**。

# 基尔霍夫定律

这两条定律不仅是电路分析的工具，更是宇宙基本物理定律——**电荷守恒**和**能量守恒**——在电路中的具体体现。

## 基尔霍夫电流定律（KCL）

### 为什么电子不能凭空堆积

- **宏观公式：** Σ I_in = Σ I_out
- **微观物理：** 电子带负电荷。根据**库仑定律**，同种电荷之间存在巨大的排斥力。如果流入某个节点的电子多于流出，负电荷将在该节点迅速积累。
- **自调节机制：** 负电荷一旦开始积累，强大的排斥力立即"推开"后续流入的电子，同时"加速"前方流出的电子。这个微观自平衡过程在几纳秒内完成。在稳态条件下，**任何节点都无法容纳多余的净电荷**；流入多少，就流出多少。

## 基尔霍夫电压定律（KVL）

### 为什么完整回路必等于零

- **宏观公式：** Σ V = 0
- **微观物理：** 在静电学或低频电路中，电场是**保守场（无旋场）**。电场力做的功只取决于起点和终点，与路径无关。

- **能量守恒类比：** 电源如同"电荷电梯"，消耗化学能将电子从低电势抬升到高电势（获得电势能）。电子流经电阻时，通过与原子的碰撞，将电梯中获得的势能全部转化为**热能**或**光能**。电子回到电池负极时，能量恰好耗尽。能量既不能凭空产生，也不能凭空消失——这就是 KVL 背后的终极真理。

# 基础电子元件

## 电阻器

![碳膜电阻截面](./18.jpg)

电阻器是一种被动电子元件，用于在电流路径中引入阻力。它的主要作用是限制电流（保护 LED 等元件不被烧毁）和分压。

### 内部结构——碳膜电阻器

1. **陶瓷芯：** 中心是一根高等级陶瓷（绝缘体）实心棒，作为结构基础
2. **碳膜层：** 陶瓷棒表面沉积一层纯碳薄膜——这就是电阻材料
3. **螺旋槽：** 螺旋路径越短越宽 = 阻值越低；越长越细 = 阻值越高
4. **端帽与引线：** 金属端帽压在棒的两端，镀锡铜引线焊接在端帽上
5. **保护涂层与色环：** 表面涂覆绝缘漆保护，彩色条纹标识阻值和精度

### 理论：分压原理

在串联电路中，电压降与电阻成正比（R↑ = V↑）。

**串联电阻计算（电压降）：**
场景：一个 LED 工作电压 3V，电流 13.5mA（0.0135A），使用 5V 电源。

- V*降 = V*源 - V_LED = 2V
- R = V\_降 / I = 2V / 0.0135A = 148.15Ω → **选用 150Ω 电阻**

### LED 可以当作电阻吗？

不能将 LED 视为固定欧姆电阻，因为它是一个非线性元件。普通电阻遵循欧姆定律（电流与电压成正比），而 LED 是二极管，具有非线性的电流-电压曲线。

电容器通过在两个被介质隔开的导电板之间建立电场来储存能量。广泛用于滤波、去耦、定时电路和能量存储。

## 电感器

![电感概览](./29.png)

电感器是一种被动电子元件，当电流通过时会将能量储存在磁场中。它由线圈绕制而成，通常带有磁芯。电感器的核心特性是阻碍电流的变化——它能平滑电流波动，抑制突变。

### 实战案例：整流桥 LC 滤波

![整流桥与电感 1](./24.png)
![整流桥与电感 2](./25.png)

在电源电路中，电感器与电容器组合构成 LC 滤波器。桥式整流器将交流转换为脉动直流后，电感器通过抑制纹波电流来平滑输出，从而获得更干净的直流电压。

## 二极管

![二极管概览](./30.png)

二极管是一种半导体器件，仅允许电流单向流动——从阳极到阴极。它是整流、保护和信号处理的基础构建模块。

## 线性电源与开关电源

![线性与开关电源概览](./31.png)

电源将输入电能转换为稳定的直流输出。两种主要拓扑为：

- **线性电源：** 使用变压器、整流器、滤波电容和线性稳压器。结构简单、噪声低，但效率低（超出部分以热量形式耗散）。
- **开关电源（SMPS）：** 使用高频开关、变压器和反馈控制。结构更复杂，但效率高、体积小。
