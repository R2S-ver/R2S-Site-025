# RC 无源滤波器概述

RC 滤波器是最基础也是最重要的信号调理电路之一。仅用一个电阻（R）和一个电容（C），就能实现对信号频率的选择性通过或阻挡。虽然结构简单，但在模拟前端设计、抗混叠滤波、去抖电路、音频处理等场景中无处不在。

## 核心原理：电容的阻抗随频率变化

电容的容抗 Xc = 1/(2πfC)，频率越高，阻抗越低；频率越低，阻抗越高。利用这一特性与电阻分压，即可实现对不同频率信号的选择性衰减。

- **低频时**：电容相当于开路（高阻抗），信号难以通过
- **高频时**：电容相当于短路（低阻抗），信号容易通过
- **截止频率 fc**：当 |Xc| = R 时，f = 1/(2πRC)，此时输出功率降至输入的一半（-3dB）

## RC 低通滤波器（Low-Pass Filter）

### 电路结构

```
Vin ── R ──┬── Vout
            │
            C
            │
           GND
```

电阻串联、电容并联到地。低频信号通过电阻到达输出端；高频信号被电容旁路到地，输出端电压极低。

### 传递函数与截止频率

- 截止频率：**fc = 1/(2πRC)**
- 高于 fc 的信号以 -20dB/decade 的斜率衰减
- 直流增益为 1（0dB），即直流信号完全通过

### 典型应用

- **抗混叠滤波**：ADC 采样前，滤除高于奈奎斯特频率（fs/2）的信号分量，防止混叠失真
- **电源纹波抑制**：滤除 DC/DC 转换器输出的高频开关纹波
- **按键去抖（硬件消抖）**：10kΩ + 100nF，fc ≈ 159Hz，远低于机械抖动频率（kHz级），有效平滑触点弹跳
- **PWM 平滑**：将 PWM 方波转换为模拟电压（简易 DAC）
- **音频低音提取**：在分频器或音调控制电路中提取低频成分

### 设计注意事项
- 后级输入阻抗需远大于 R，否则分压比改变，截止频率漂移
- 单级 RC 衰减较缓（-20dB/dec），若需更陡截止，可级联多级或采用有源滤波器
- 电容选型：信号通路优先使用 C0G/NP0 或薄膜电容，避免 X7R 等压电/非线性电容引入失真

## RC 高通滤波器（High-Pass Filter）

### 电路结构

```
Vin ── C ──┬── Vout
            │
            R
            │
           GND
```

电容串联、电阻并联到地。高频信号通过电容到达输出端；低频信号被电容阻挡，输出端经电阻拉到地。

### 传递函数与截止频率

- 截止频率：**fc = 1/(2πRC)**
- 低于 fc 的信号以 -20dB/decade 的斜率衰减
- 频率无穷大时增益趋近于 1（0dB），即高频信号完全通过

### 典型应用

- **交流耦合/隔直**：去除传感器信号中的直流偏置，只提取交流变化分量
- **音频耦合**：前后级之间的交流耦合电容，隔离不同级之间的直流工作点
- **PIR 传感器信号提取**：人体移动引起的红外变化是交流信号，通过高通滤除缓慢的环境温度漂移
- **ECG/生物电信号**：去除电极半电池电位产生的直流偏移（通常几个mV到几百mV）
- **音频高音提取**：在分频器中提取高频成分给高音扬声器

### 设计注意事项
- 截止频率设置需保证目标信号频段内衰减可忽略（fc << f_min）
- 前级输出阻抗与 R 构成分压，影响通带增益——R 需足够大
- 隔直电容容值不能过大，否则上电浪涌电流会持续较长时间

## RC 带通滤波器

将高通与低通级联（高通在前、低通在后，中间可加缓冲），即可构成带通滤波器：

```
Vin ── C1 ──┬── R1 ──┬── Vout
             │        │
             R2       C2
             │        │
            GND      GND
```

- 下截止频率 f_L = 1/(2π·R2·C1)，由高通级决定
- 上截止频率 f_H = 1/(2π·R1·C2)，由低通级决定
- 带宽 BW = f_H - f_L，中心频率 f_0 = √(f_L · f_H)

典型应用：音频均衡器、通信接收机中频滤波、特定频率信号的提取与检测。

## 时域响应特性

RC 电路在时域中也有重要意义：

- **时间常数 τ = RC**
- 阶跃响应：Vout(t) = V_final × (1 - e^(-t/τ))（充电），Vout(t) = V_initial × e^(-t/τ)（放电）
- 经过 1τ，电压变化约 63.2%；经过 5τ，变化超过 99.3%，可认为稳态
- 这一特性在定时电路、复位电路、延时时序和消抖中无处不在

## 有源滤波器简介（预习钩子）

无源 RC 滤波器的局限：
- 带负载能力弱（输出阻抗高）
- 无法提供增益
- 单级衰减率有限

有源滤波器在 RC 网络后加运放形成缓冲和增益，同时引入反馈实现更复杂的滤波特性：
- **Sallen-Key 拓扑**：最常用的二阶有源滤波器结构
- **多路反馈（MFB）**：适合高 Q 值应用
- **开关电容滤波器**：时钟可调截止频率，适合集成化

理解了 RC 无源滤波，就掌握了所有滤波器设计的根基。
